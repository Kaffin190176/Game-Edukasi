📖 Istilah Penting

Root → simpul paling atas/akar
Node → setiap bagian/simpul dalam Tree
Parent → simpul yang memiliki anak
Child → simpul turunan dari parent
Sibling → node yang memiliki parent sama
Leaf → node yang tidak memiliki anak
Edge → hubungan antara dua node
Level → tingkatan node
Subtree → bagian dari sebuah tree
Vertex/Node → titik atau objek
Degree → jumlah hubungan sebuah node
Path → jalur dari satu node ke node lainnya
Connected → node-node saling terhubung
Directed Graph → hubungan memiliki arah
Undirected Graph → hubungan tidak memiliki arah
Weighted Graph → hubungan memiliki nilai/bobot
